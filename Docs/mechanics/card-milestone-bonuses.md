## Концепция

Каждая из 8 карт получает ОДИН качественный (не только числовой) бонус, разлочиваемый на текущем максимальном уровне прокачки (5). Переиспользует идеи из замороженного roguelite-каталога эффектов (`RunUpgradeDefinition.cs`, T1-тир), но ретюнутые под постоянный (не одноразовый) контекст. Даёт игроку среднесрочную причину качать карты за пределами плоского роста статов.

**Зафиксированный скоуп:**
- Один бонус на карту, на текущем max level (5). НЕ расширяем maxLevel до множественных тиров сейчас — иначе придётся пересчитывать всю кривую стоимости прокачки за shard-валюту.
- Все 8 карт получают бонус для симметрии (не только 4 карты, для которых уже есть готовый код).

## Техническая зависимость — ОБНОВЛЕНО 29.08.2026

Изначально (23.08.2026) считалось, что все 8 бонусов упираются в персистентное хранилище модификаторов/флагов — см. `Docs/mechanics/persistent-modifier-store.md`. Проверка кода всех 8 контроллеров (`Docs/CARD_SYSTEM_DESIGN.md` §5) показала, что это не так: каждый контроллер уже читает текущий уровень карты напрямую из `PlayerProfile.Instance.ownedCardsProgress` при старте. Бонус 5 уровня — это независимая проверка `if (currentLevel >= 5)` рядом с существующим кодом, без новой инфраструктуры. Готовые исполняемые брифы: `Docs/CLAUDE_CODE_TASK_Cards_Bonuses_A.md` (Barricade/Sniper/Bomb/Car) и `_B.md` (CombatHelicopter/Soldier/Bait/Helicopter).

Персистентное хранилище (`persistent-modifier-store.md`) остаётся нужным ТОЛЬКО для будущего Talent Tree — не для этой механики.
